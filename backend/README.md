# Backend Perpustakaan Digital

- Administrator dan petugas memiliki dashboard terpisah.
- Administrator dan petugas sama-sama dapat membuat laporan peminjaman.
- Laporan dapat difilter berdasarkan tanggal dan status, lalu dicetak atau disimpan sebagai PDF melalui dialog print browser.
- Menu Pengguna hanya tersedia untuk administrator.
- Semua tombol Keluar memakai dialog konfirmasi sebelum session dihapus.
